# Saryarka Kitchen Website

## Project Title and Topic

**Saryarka Kitchen** — a multi-page responsive website for a Kazakh and Central Asian restaurant in Astana.

## Group Members

* Matiullah Zaman
* Zainap Noori

## Short Description

Saryarka Kitchen is a responsive restaurant website designed to present a Kazakh and Central Asian restaurant. The website contains five pages with information about the restaurant, its menu, food gallery, and table reservations.

The website uses a wine red, saffron gold, and cream color theme to create a warm restaurant-style design.

## Pages

The website includes five connected pages:

1. **Home** — introduction to the restaurant and featured content.
2. **About** — information about the restaurant, team, and working hours.
3. **Menu** — restaurant dishes and prices presented in a table.
4. **Gallery** — photos of the restaurant and food.
5. **Reservations** — a form for making a table reservation.

All pages are connected through the navigation bar.

## Features Implemented

* Five connected HTML pages: Home, About, Menu, Gallery, and Reservations.
* Sticky navigation bar available across the website.
* Semantic HTML5 elements such as:

  * `header`
  * `nav`
  * `main`
  * `section`
  * `article`
  * `aside`
  * `figure`
  * `footer`
* A menu table with dishes and prices.
* A reservation form with different input fields.
* External CSS file: `css/style.css`.
* Flexbox for layouts such as the header, footer, hours card, and team cards.
* CSS Grid for the gallery, team section, and chef's picks.
* CSS positioning using `sticky`, `relative`, and `absolute`.
* Interactive effects using:

  * `:hover`
  * `:focus`
  * `:focus-visible`
* `:nth-child()` selectors for different table rows, cards, and captions.
* CSS variables using `:root`.
* Google Fonts: Fraunces and Nunito Sans.
* Lazy loading for gallery images using `loading="lazy"`.
* Responsive design using media queries.
* Bootstrap 5.3 grid and utility classes.

## Responsive Design

The website is designed to work on different screen sizes.

Media queries are used for:

* **992px** — tablet and smaller desktop screens.
* **576px** — mobile screens.

On smaller screens, the layout changes to make the content easier to read and navigate. The header and navigation also become vertical on mobile devices.
